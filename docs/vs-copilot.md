# Copilot と、先代の同僚チャットとの線

Microsoft 365 Copilot は、SharePoint と Outlook と Teams の中を探す仕事が速い。
Azure OpenAI の上に載せた全社員向けチャットは、翻訳と要約と議事録が速い。
社内イントラを後から足した RAG も、資料を探す仕事はこなす。

どちらも、次を自前の正本として持ちにくい。

- 業務の関係（グラフ）
- マニュアルに無い口伝と、失敗の教訓
- それを回すスキル
- 実行の手前で止める承認
- 組織ごとのトークン課金
- プロンプトとログを閉域に閉じる設計

先代を否定しない。
探す仕事と書く仕事は、先代のまま残してよい。
申請と口伝と課金が要件になったら、このテンプレに移す。
