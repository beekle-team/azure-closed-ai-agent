# 架空の総合商社サンプル

`agent/samples/shosha/` は、実在の会社ではない。
マニュアルに無い確認を、スキルとして回すところを見せるための台本である。

汎用チャットが得意なのは、翻訳と要約と資料検索である。
サンプルが足すのは、画面に項目が無い確認と、送信の手前で止まる承認である。

## 口伝を4つ入れてある

出張の保険は契約管理部が見る。申請画面に項目が無い。
金属の大型稟議は、本部長の前に財務へ話す。経路表に無い。
取引先与信は、金額より先に「初めてかどうか」を見る。
事業投資で後から効くのは、数字より論点漏れである。

スキルは、この口伝を手順に書き換えたファイルである。
中身は http://admin.localhost/skills でも見える。

## 動かしたあとに聞く文

http://admin.localhost/chat を開く。ログイン後、画面が FastAPI を呼ぶ。

「海外出張の申請、画面に出てこない確認事項は？」と聞くと、マニュアルの欠落と口伝が並ぶ。
「出張事前チェックを回して」と言うと、契約管理部への一声まで含めて実行する。
「事業投資の申請チェックを回して」は、失敗の教訓の3論点を先に返す。
「契約レビュー依頼を法務に送信して」は、本文を載せず、承認待ちで止まる。

原本を足すときは `POST /v1/ingest`。
件名が「口伝」のメールを `/v1/channels/mail` に流しても、同じ取り込みになる。
Teams の発言は `/v1/channels/teams` が受けて、ブラウザと同じスキルを回す。
