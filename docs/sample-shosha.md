# サンプル: 同僚チャットの次

先代は、全社員に配った Azure OpenAI の同僚である。
翻訳、要約、議事録、あとから足した社内検索までは、それで足りた。

置き換える理由は、そこから先である。
マニュアルに無い確認と、過去の失敗の教訓を、スキルとして回す。
申請の送信は、人の承認で止める。

社員が聞く相手は、まだチャットに見える。
裏側は検索計画とグラフとスキル実行である。

## 口伝を正本として残す

サンプルに入れた口伝は4つ。

出張の保険は契約管理部が見る。申請画面に項目が無い。
金属の大型稟議は、本部長の前に財務へ話す。経路表に無い。
取引先与信は、金額より先に「初めてかどうか」を見る。
事業投資で後から効くのは、数字より論点漏れである。

汎用チャットは、この4つを出さない。
スキルは、口伝を手順に書き換えたものである。

## 動かすと見られること

http://admin.localhost/chat を開く。ログイン後、Inertia の画面が FastAPI を呼ぶ。

「海外出張の申請、画面に出てこない確認事項は？」と聞くと、マニュアルの欠落と口伝が並ぶ。
「出張事前チェックを回して」と言うと、契約管理部への一声まで含めて実行する。
「事業投資の申請チェックを回して」は、失敗の教訓の3論点を先に返す。
「契約レビュー依頼を法務に送信して」は、本文を載せず、承認待ちで止まる。

原本を足すときは `POST /v1/ingest`。
全文インデックスとグラフが同じタイミングで更新される。
