# サンプル: 総合商社の社内AIチャット

配布用の中身は、総合商社の社内アシスタントである。
社員が聞く相手はチャットに見える。裏側はエージェントの実行基盤で、口伝をスキルにする。

部署ごとの規程と、画面に出てこない確認が同時にある。
マニュアルをベクトル検索するだけでは、現場の一声が落ちる。

## 口伝を正本として残す

サンプルに入れた口伝は3つ。

出張の保険は契約管理部が見る。申請画面に項目が無い。
金属の大型稟議は、本部長の前に財務へ話す。経路表に無い。
取引先与信は、金額より先に「初めてかどうか」を見る。

いずれも誰かの頭の中にあった確認を、文書庫とグラフのノードにした。
スキルは、その口伝を手順に書き換えたものである。

## 動かすと見られること

http://admin.localhost/chat を開く。ログイン後、Inertia の画面が FastAPI を呼ぶ。

「海外出張の申請、画面に出てこない確認事項は？」と聞くと、マニュアルの欠落と口伝が並ぶ。
「出張事前チェックを回して」と言うと、契約管理部への一声まで含めて実行する。
「契約レビュー依頼を法務に送信して」は、本文を載せず、承認待ちで止まる。

原本を足すときは `POST /v1/ingest`。
全文インデックスとグラフが同じタイミングで更新される。
